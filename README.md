# AbsentServices Web Template

A clean, modern, dark-themed responsive website template built with **Bootstrap 4**, **Font Awesome 5**, and custom CSS. Designed specifically for gaming networks, Minecraft communities, digital marketplaces, and service platforms.

## 🌟 Features

- **Responsive Layout:** Works smoothly across mobile, tablet, and desktop devices.
- **Pre-designed Pages:**
  - `index.html` — Homepage featuring a heroic header, featured icons, and an "About Us" section.
  - `marketplace.html` — Display products, downloads, external store links, and ad banners.
  - `serverlist.html` — Showcase Minecraft or community server listings and banner slots.
- **Custom Styling:** Modern dark theme `#212529` / `#343a40` paired with vibrant red accent colors (`#fb2d2d`).
- **Icon & Font Integration:** Built-in support for Google Fonts (*Montserrat*, *Roboto Slab*, *Droid Serif*) and Font Awesome 5 icons.
